**Course:** Programming for AI / ML Lab  
**Source presentation:** `Lab 12 Decision Tree.pptx`  
**Dataset:** Uploaded `diabetes.csv` (768 records, 8 inputs, 1 target)

## Important source note

The uploaded slides contain **theory**, including Decision Tree terminology,
entropy, information gain, ID3 and worked illustrations. They do **not** include
copy-paste Python lab code or explicit programming tasks. These five runnable
tasks are an original Python **implementation of the lecture concepts** using
your uploaded diabetes dataset; they are not verbatim slide code.

Classic ID3 generally handles categorical attributes; the implementation here
uses `sklearn.tree.DecisionTreeClassifier(criterion="entropy")`, which builds
CART-style binary trees and chooses entropy-reducing splits. This demonstrates
the lecture's information-gain idea but is not a strict ID3 implementation.

## Data and model details

- **Input features:** `Pregnancies`, `Glucose`, `BloodPressure`,
  `SkinThickness`, `Insulin`, `BMI`, `DiabetesPedigreeFunction`, `Age`.
- **Output:** `Outcome`, where 0 means no diabetes recorded, 1 means diabetes recorded.
- **Train/test:** 80% / 20%, stratified, `random_state=42`.
- **Algorithm:** Entropy-based Decision Tree (`max_depth=4`, `min_samples_leaf=10`)
  for simple explanations and basic pruning.
- **Metrics:** Accuracy, Precision, Recall, F1-score and Confusion Matrix.
- **Charts:** Class distribution, Decision Tree, Feature Importance, Confusion Matrix.
- **Data integrity:** The CSV is preserved exactly as uploaded. Zero entries in
  clinical fields can represent missing measurements; they are reported but
  **not silently replaced** in this baseline lesson.
